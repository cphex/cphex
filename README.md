cphex
=====

This repo is for discussing and organising meetings and events for the Copenhagen Elixir (CPH Ex) group.

If you are here looking for information about the next "_Elixir Meetup_", go to the [issues section](https://github.com/cphex/cphex/issues) of this repo. We discuss and organise meetups in the issues there.

**Keep up to date:** We recommend using the official channels reccomended on the [Elixir lang website](https://elixir-lang.org). You can find information about irc, Slack, Discord, forum and more there.

New to Elixir?
--------------

Read the [Getting started guide](http://elixir-lang.org/getting-started/introduction.html) on the elixir-lang.org site

Then practice your skills on [exercism.io](http://exercism.io)
